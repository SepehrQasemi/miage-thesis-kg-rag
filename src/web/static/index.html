Using The Application

Operational guide for importing, searching, graph exploration, and RAG.

1. Start And Check

Start Neo4j, run the app, then use the dashboard to confirm the graph is loaded.

docker compose up -d neo4j python scripts/doctor.py

2. Import PDFs

Open Import PDFs, select one or more files, review extracted fields, then approve or discard each draft.

  • Only valid PDF content is accepted.
  • Duplicate files are detected automatically.
  • Approved metadata is stored in Neo4j.

3. Search Theses

Use Thesis Search for title, concept, keyword, use-case, methodology, year, level, and track filtering.

Open a thesis profile to inspect graph links and access the source PDF.

4. Explore The Graph

Use Knowledge Graph to inspect how theses connect to concepts, methods, use cases, years, levels, and tracks.

Click any node to see direct connections in the inspector.

5. Ask / RAG

Ask questions over thesis metadata. The system shows only sources above the relevance threshold.

Use Show all results for paginated relevant sources instead of forcing weak matches.

6. Export And Validate

Use Dataset to view, copy, or download CSV. Maintenance commands read from Neo4j.

python scripts/validate_dataset.py python scripts/validate_knowledge_graph.py
